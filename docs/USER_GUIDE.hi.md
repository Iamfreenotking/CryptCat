# CryptCat चित्रों वाली आसान गाइड

यह गाइड Web संस्करण के लिए है। फ़ाइल और पासवर्ड आपके डिवाइस पर ही काम करते हैं। सामान्य एन्क्रिप्शन और डिक्रिप्शन के लिए अकाउंट या इंटरनेट की जरूरत नहीं है।

## फ़ाइल एन्क्रिप्ट करें

### चरण 1: फ़ाइल चुनें

पेज खोलें और **फ़ाइल चुनें** दबाएँ। फोटो, वीडियो, ऑडियो, PDF, TXT, ZIP या कोई दूसरी फ़ाइल चुनें। नाम और आकार दिखाई देगा।

![चरण 1: फ़ाइल चुनें](images/web-step-1-select-file.png)

### चरण 2: पासवर्ड लिखें और फिर से पक्का करें

**एन्क्रिप्शन पासवर्ड** में पासवर्ड लिखें। **पासवर्ड की पुष्टि करें** में वही पासवर्ड फिर लिखें। दोनों पासवर्ड एक जैसे होने पर ही आगे बढ़ें।

![चरण 2: पासवर्ड लिखें और पक्का करें](images/web-step-2-password.png)

### चरण 3: एन्क्रिप्ट करके सेव करें

**एन्क्रिप्ट करके सेव करें** दबाएँ। ब्राउज़र `.cryptcat` पर खत्म होने वाली नई फ़ाइल सेव करेगा। सेव होने तक पेज बंद या रीफ्रेश न करें।

![चरण 3: एन्क्रिप्ट करके सेव करें](images/web-step-3-encrypt.png)

## फ़ाइल डिक्रिप्ट करें

### चरण 4: एन्क्रिप्ट की गई फ़ाइल चुनें

**डिक्रिप्ट** खोलें, **एन्क्रिप्ट की गई फ़ाइल चुनें** दबाएँ और `.cryptcat` फ़ाइल चुनें। पुरानी `.crypt3` फ़ाइल भी अपने-आप पहचानी जाती है।

### चरण 5: डिक्रिप्शन पासवर्ड लिखें

**डिक्रिप्शन पासवर्ड** में असली पासवर्ड लिखें। गलत पासवर्ड पर काम विफल होना चाहिए; गलत नतीजे को सही फ़ाइल नहीं माना जाएगा।

### चरण 6: डिक्रिप्ट करके सेव करें

**डिक्रिप्ट करके सेव करें** दबाएँ। कोई कॉपी मिटाने से पहले वापस मिली फ़ाइल खोलकर जाँच लें।

## सुरक्षा और ऑफलाइन उपयोग

पासवर्ड खोने पर CryptCat फ़ाइल वापस नहीं ला सकता। पासवर्ड, API key, signing key या निजी फ़ाइलें प्रकाशित न करें। ऑफलाइन जाँच के लिए इंटरनेट बंद करके सभी छह चरण दोहराएँ।
