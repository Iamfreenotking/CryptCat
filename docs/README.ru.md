# CryptCat простыми словами

CryptCat шифрует и расшифровывает файлы прямо на устройстве: фотографии, видео, аудио, PDF, TXT, ZIP и другие файлы.

Выберите файл, введите пароль, подтвердите его и нажмите «Зашифровать и сохранить». Формат v2 создаёт файл `.cryptcat`. Для расшифровки выберите файл и введите тот же пароль. Старые файлы `.crypt3` распознаются автоматически.

В v2 Argon2id или scrypt получают ключ 256 бит из пароля, а XChaCha20-Poly1305 или AES-256-GCM шифруют и проверяют данные. Для старых файлов сохранён путь AES-256-CBC.

Веб-версия работает без интернета. Разместите содержимое `www/` на OpenResty, Nginx или Apache. Для локальной проверки выполните `cd www && python3 -m http.server 8080`.
