# সহজ ভাষায় CryptCat

CryptCat আপনার ডিভাইসেই ফাইল এনক্রিপ্ট ও ডিক্রিপ্ট করে। ছবি, ভিডিও, অডিও, PDF, TXT এবং ZIP ফাইল ব্যবহার করা যায়।

ফাইল বেছে নিন, পাসওয়ার্ড লিখুন, আবার নিশ্চিত করুন, তারপর “Encrypt and save” চাপুন। v2 একটি `.cryptcat` ফাইল তৈরি করে। ডিক্রিপ্ট করতে একই পাসওয়ার্ড দিন। পুরনো `.crypt3` ফাইল নিজে থেকে চেনা হয়।

v2 পাসওয়ার্ড থেকে 256-বিট কী বানাতে Argon2id বা scrypt ব্যবহার করে এবং ডেটা এনক্রিপ্ট ও যাচাই করতে XChaCha20-Poly1305 বা AES-256-GCM ব্যবহার করে। পুরনো ফাইলের জন্য AES-256-CBC সামঞ্জস্য রাখা হয়েছে।

Web সংস্করণ অফলাইনে চলে। `www/` ফোল্ডারটি static server-এ প্রকাশ করুন। স্থানীয় পরীক্ষায় `cd www && python3 -m http.server 8080` চালান।
