# Guide visuel de CryptCat, étape par étape

Ce guide explique la version Web. Les fichiers et les mots de passe sont traités sur votre appareil. Le chiffrement et le déchiffrement normaux ne demandent ni compte ni connexion Internet.

## Chiffrer un fichier

### Étape 1 : choisir un fichier

Ouvrez la page et cliquez sur **Choisir un fichier**. Sélectionnez une photo, une vidéo, un fichier audio, un PDF, un TXT, un ZIP ou un autre fichier. Le nom et la taille s’affichent.

![Étape 1 : choisir un fichier](images/web-step-1-select-file.png)

### Étape 2 : saisir et confirmer le mot de passe

Saisissez un mot de passe dans **Mot de passe de chiffrement**, puis saisissez-le à nouveau dans **Confirmer le mot de passe**. Continuez seulement quand les deux mots de passe sont identiques.

![Étape 2 : saisir et confirmer le mot de passe](images/web-step-2-password.png)

### Étape 3 : chiffrer et enregistrer

Cliquez sur **Chiffrer et enregistrer**. Le navigateur enregistre un nouveau fichier qui se termine par `.cryptcat`. Ne fermez pas et ne rechargez pas la page pendant l’enregistrement.

![Étape 3 : chiffrer et enregistrer](images/web-step-3-encrypt.png)

## Déchiffrer un fichier

### Étape 4 : choisir le fichier chiffré

Ouvrez **Déchiffrer**, cliquez sur **Choisir un fichier chiffré**, puis sélectionnez le fichier `.cryptcat`. Les anciens fichiers `.crypt3` sont reconnus automatiquement.

### Étape 5 : saisir le mot de passe de déchiffrement

Saisissez le mot de passe original dans **Mot de passe de déchiffrement**. Un mauvais mot de passe doit échouer, sans produire un faux fichier récupéré.

### Étape 6 : déchiffrer et enregistrer

Cliquez sur **Déchiffrer et enregistrer**. Ouvrez le fichier restauré et vérifiez son contenu avant de supprimer une copie.

## Sécurité et mode hors ligne

Si vous perdez le mot de passe, CryptCat ne peut pas récupérer le fichier. Ne publiez jamais de mot de passe, de clé API, de clé de signature ou de fichier privé. Pour tester le mode hors ligne, coupez Internet et répétez les six étapes.
