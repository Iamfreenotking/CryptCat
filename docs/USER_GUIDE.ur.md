# CryptCat کی تصویروں والی آسان رہنما

یہ رہنما Web ورژن کے لیے ہے۔ فائلیں اور پاس ورڈ آپ کے آلے پر ہی کام کرتے ہیں۔ عام طور پر خفیہ کرنے اور کھولنے کے لیے اکاؤنٹ یا انٹرنیٹ ضروری نہیں۔

## فائل کو خفیہ کریں

### مرحلہ 1: فائل منتخب کریں

صفحہ کھولیں اور **فائل منتخب کریں** دبائیں۔ تصویر، ویڈیو، آڈیو، PDF، TXT، ZIP یا کوئی دوسری فائل منتخب کریں۔ نام اور سائز دکھائی دے گا۔

![مرحلہ 1: فائل منتخب کریں](images/web-step-1-select-file.png)

### مرحلہ 2: پاس ورڈ لکھیں اور تصدیق کریں

**خفیہ کرنے کا پاس ورڈ** میں پاس ورڈ لکھیں۔ **پاس ورڈ کی تصدیق** میں وہی پاس ورڈ دوبارہ لکھیں۔ دونوں پاس ورڈ ایک جیسے ہوں تو ہی آگے بڑھیں۔

![مرحلہ 2: پاس ورڈ لکھیں اور تصدیق کریں](images/web-step-2-password.png)

### مرحلہ 3: خفیہ کر کے محفوظ کریں

**خفیہ کر کے محفوظ کریں** دبائیں۔ براؤزر `.cryptcat` پر ختم ہونے والی نئی فائل محفوظ کرے گا۔ محفوظ ہونے تک صفحہ بند یا ریفریش نہ کریں۔

![مرحلہ 3: خفیہ کر کے محفوظ کریں](images/web-step-3-encrypt.png)

## فائل کھولیں

### مرحلہ 4: خفیہ فائل منتخب کریں

**فائل کھولیں** والا حصہ کھولیں، **خفیہ فائل منتخب کریں** دبائیں اور `.cryptcat` فائل منتخب کریں۔ پرانی `.crypt3` فائل بھی خودکار طور پر پہچانی جاتی ہے۔

### مرحلہ 5: فائل کھولنے کا پاس ورڈ لکھیں

**فائل کھولنے کا پاس ورڈ** میں اصل پاس ورڈ لکھیں۔ غلط پاس ورڈ پر عمل ناکام ہونا چاہیے، غلط نتیجہ درست فائل نہیں سمجھا جائے گا۔

### مرحلہ 6: کھول کر محفوظ کریں

**کھول کر محفوظ کریں** دبائیں۔ کوئی نقل مٹانے سے پہلے واپس ملنے والی فائل کھول کر دیکھیں۔

## حفاظت اور آف لائن استعمال

پاس ورڈ بھولنے پر CryptCat فائل واپس نہیں لا سکتا۔ پاس ورڈ، API key، signing key یا نجی فائلیں شائع نہ کریں۔ آف لائن جانچ کے لیے انٹرنیٹ بند کر کے یہ چھ مراحل دوبارہ کریں۔
