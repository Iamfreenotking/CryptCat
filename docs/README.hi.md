# CryptCat आसान भाषा में

CryptCat आपके डिवाइस पर ही फ़ाइलों को एन्क्रिप्ट और डिक्रिप्ट करता है। फोटो, वीडियो, ऑडियो, PDF, TXT और ZIP फ़ाइलें चुनी जा सकती हैं।

## इस्तेमाल कैसे करें

फ़ाइल चुनें, पासवर्ड डालें, पासवर्ड फिर से पक्का करें और “Encrypt and save” दबाएँ। v2 में `.cryptcat` फ़ाइल बनती है। डिक्रिप्शन में वही पासवर्ड डालें और “Decrypt and save” दबाएँ। पुराने `.crypt3` फ़ाइल अपने आप पहचाने जाते हैं।

## सुरक्षा

v2 में Argon2id या scrypt पासवर्ड से 256-बिट कुंजी बनाते हैं। XChaCha20-Poly1305 या AES-256-GCM फ़ाइल को एन्क्रिप्ट और जाँचते हैं। पुरानी `.crypt3` फ़ाइलों के लिए AES-256-CBC वाला पुराना रास्ता रखा गया है।

## ऑफलाइन चलाना

`www/` की सामग्री को किसी static web server पर रखें। किसी खाते, API key या इंटरनेट की जरूरत नहीं है। स्थानीय परीक्षण के लिए `cd www && python3 -m http.server 8080` चलाएँ।
