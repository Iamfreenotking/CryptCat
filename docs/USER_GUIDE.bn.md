# CryptCat ছবিসহ ধাপে ধাপে নির্দেশিকা

এই নির্দেশিকা Web সংস্করণের জন্য। ফাইল ও পাসওয়ার্ড আপনার ডিভাইসেই প্রক্রিয়া হয়। সাধারণভাবে এনক্রিপ্ট বা ডিক্রিপ্ট করতে অ্যাকাউন্ট বা ইন্টারনেট লাগে না।

## ফাইল এনক্রিপ্ট করুন

### ধাপ ১: ফাইল বেছে নিন

পেজ খুলে **ফাইল বেছে নিন** চাপুন। ছবি, ভিডিও, অডিও, PDF, TXT, ZIP বা অন্য ফাইল বেছে নিন। নাম ও আকার দেখা যাবে।

![ধাপ ১: ফাইল বেছে নেওয়া](images/web-step-1-select-file.png)

### ধাপ ২: পাসওয়ার্ড লিখে নিশ্চিত করুন

**এনক্রিপশন পাসওয়ার্ড** ঘরে পাসওয়ার্ড লিখুন। **পাসওয়ার্ড নিশ্চিত করুন** ঘরে একই পাসওয়ার্ড আবার লিখুন। দুই পাসওয়ার্ড এক না হওয়া পর্যন্ত এগোবেন না।

![ধাপ ২: পাসওয়ার্ড লেখা ও নিশ্চিত করা](images/web-step-2-password.png)

### ধাপ ৩: এনক্রিপ্ট করে সংরক্ষণ করুন

**এনক্রিপ্ট করে সংরক্ষণ করুন** চাপুন। ব্রাউজার `.cryptcat` দিয়ে শেষ হওয়া একটি নতুন ফাইল সংরক্ষণ করবে। সংরক্ষণ শেষ না হওয়া পর্যন্ত পেজ বন্ধ বা রিফ্রেশ করবেন না।

![ধাপ ৩: এনক্রিপ্ট করে সংরক্ষণ](images/web-step-3-encrypt.png)

## ফাইল ডিক্রিপ্ট করুন

### ধাপ ৪: এনক্রিপ্ট করা ফাইল বেছে নিন

**ডিক্রিপ্ট** খুলে **এনক্রিপ্ট করা ফাইল বেছে নিন** চাপুন এবং `.cryptcat` ফাইল বেছে নিন। পুরোনো `.crypt3` ফাইলও নিজে থেকে শনাক্ত হয়।

### ধাপ ৫: ডিক্রিপশন পাসওয়ার্ড লিখুন

**ডিক্রিপশন পাসওয়ার্ড** ঘরে আসল পাসওয়ার্ড লিখুন। ভুল পাসওয়ার্ডে কাজ ব্যর্থ হবে; ভুল ফলকে সফল ফাইল হিসেবে দেখানো হবে না।

### ধাপ ৬: ডিক্রিপ্ট করে সংরক্ষণ করুন

**ডিক্রিপ্ট করে সংরক্ষণ করুন** চাপুন। কোনো কপি মুছে ফেলার আগে ফিরে পাওয়া ফাইল খুলে দেখুন।

## নিরাপত্তা ও অফলাইন ব্যবহার

পাসওয়ার্ড হারালে CryptCat ফাইল ফিরিয়ে দিতে পারবে না। পাসওয়ার্ড, API key, সই করার key বা ব্যক্তিগত ফাইল প্রকাশ করবেন না। অফলাইন পরীক্ষা করতে ইন্টারনেট বন্ধ করে ছয়টি ধাপ আবার করুন।
