# CryptCat بلغة بسيطة

يقوم CryptCat بتشفير الملفات وفك تشفيرها على جهازك مباشرة، مثل الصور والفيديو والصوت وملفات PDF وTXT وZIP.

اختر ملفًا، اكتب كلمة المرور، أكدها، ثم اضغط «تشفير وحفظ». ينشئ الإصدار v2 ملفًا بامتداد `.cryptcat`. لفك التشفير، اختر الملف واكتب كلمة المرور نفسها واضغط «فك التشفير والحفظ». يتم التعرف على ملفات `.crypt3` القديمة تلقائيًا.

يستخدم v2 خوارزمية Argon2id أو scrypt لاشتقاق مفتاح 256 بت، ثم XChaCha20-Poly1305 أو AES-256-GCM للتشفير والتحقق. يبقى مسار AES-256-CBC متاحًا للتوافق مع الملفات القديمة.

نسخة الويب ثابتة وتعمل دون إنترنت. انشر محتوى `www/` على OpenResty أو Nginx أو Apache. للاختبار المحلي استخدم `cd www && python3 -m http.server 8080`.
