## 5. English Metadata

Promotional Text:
Encrypt and decrypt files offline. Files and passwords stay on your device.

Description:
CryptCat is an offline file encryption tool for iPhone and iPad. It helps you encrypt and decrypt photos, videos, documents, archives, PDFs, text files, and other file types directly on your device.

Files and passwords stay on your device. CryptCat does not require an internet connection for core encryption and decryption.

Key features:
- Offline AES-256-CBC file encryption
- Encrypt and decrypt many common file formats
- Works with Files and supported shared documents
- Password confirmation and password fingerprint checks
- Multilingual interface
- Open-source friendly design

Important: Keep your password safe. CryptCat cannot recover lost passwords.

Keywords:
encryption,offline,file,privacy,AES,password,secure,crypt3,document,photo

What's New:
Initial release. Offline file encryption and decryption for iPhone and iPad.
