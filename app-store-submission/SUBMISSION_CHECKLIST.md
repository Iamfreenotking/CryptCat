# CryptCat App Store Submission Checklist

Prepared date: 2026-06-25

## Completed Locally

- App Store submission folder created.
- iPhone 6.9 screenshots generated at 1320 x 2868.
- iPad 13 screenshots generated at 2048 x 2732.
- Native iPhone 16 Pro Max Simulator screenshot generated at 1320 x 2868.
- Native iPad Pro 13-inch Simulator screenshot generated at 2064 x 2752.
- iPhone 16 Pro Max Simulator build and launch passed.
- iPad Pro 13-inch Simulator build and launch passed.
- App Store Connect field draft prepared.
- App Review notes prepared.
- Privacy policy draft prepared.

## Must Be Completed In Apple Developer / App Store Connect

1. Create or select the app record for Bundle ID `com.bullbullgo.crypt3`.
2. Upload the final archive build from Xcode or Transporter.
3. Select build `1.0 (1)` for App Review.
4. Fill App Information:
   - Name: `CryptCat`
   - Subtitle: `Offline File Encryption`
   - Category: `Utilities`
   - Secondary Category: `Productivity`
   - Age Rating: complete questionnaire truthfully.
5. Fill Pricing and Availability:
   - Price: Free
   - Availability: all countries/regions after export compliance clearance.
   - Release: manual release after approval.
6. Fill App Privacy:
   - Tracking: No
   - Data Collection: Data Not Collected
   - Privacy Policy URL: `https://bullbullgo.com/privacy/cryptcat`
7. Fill Version Metadata:
   - Promotional text, description, keywords, support URL, screenshots, and review notes from the prepared files.
8. Complete Export Compliance:
   - Uses encryption: Yes
   - Purpose: local file encryption/decryption
   - Upload documentation if App Store Connect requests it.
9. Submit for review.
